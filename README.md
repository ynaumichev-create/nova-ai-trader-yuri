# NOVA AI Trader v1.1 — Autonomous Paper Trading

Стабильная автономная тестовая версия.

## Что делает

- сканирует 150 криптовалют;
- запускается каждые 30 минут через GitHub Actions;
- открывает и закрывает только виртуальные сделки;
- хранит портфель, историю сделок и кривую капитала в папке `data`;
- рассчитывает Win Rate и Profit Factor.

## Установка

Загрузите все файлы и папки из архива в корень GitHub-репозитория.
